# Lionel Messi Performance Analysis Dashboard | Power BI

## Project Overview

An interactive **Lionel Messi Performance Analysis Dashboard** developed using Microsoft Power BI to analyze Lionel Messi's football performance across different competitions, opponents, and years.

This dashboard provides insights into his goals, assists, Man of the Match awards, match ratings, favourite opponents, and home vs away goal contributions through interactive visualizations.

## 🛠️ Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Data Cleaning & Transformation
- Data Visualization

## 📊 Key Performance Indicators (KPIs)
- **Total Man of the Match Awards:** 389
- **Total Goals Scored:** 521
- **Average Match Rating:** 9.25
- **Total Assists:** 389
- **Shots on Target:** 1.11K

## 📈 Dashboard Features

### 1. Overall Performance Analysis
- Total Man of the Match awards
- Total goals scored
- Average match rating
- Total assists
- Shots on target

### 2. Competition-wise Match Rating
- Average match rating across different competitions.
- Performance comparison across La Liga, Copa del Rey, Champions League, World Cup, Copa America, and Ligue 1.

### 3. Favourite Opponents Analysis
- Identifies favourite opponents based on performance.
- Compares performance against different football clubs.

### 4. Goals by Competition
- Analyzes goals scored in different competitions.
- Highlights competitions with the highest goal contributions.

### 5. Year-wise Goals Analysis
- Tracks goals scored across different years.
- Identifies yearly scoring trends.

### 6. Home vs Away Goals
- Compares goals scored in home and away matches.
- Analyzes goal distribution based on match location.

## 🎯 Project Objectives
- Analyze Lionel Messi's football performance.
- Understand his goal-scoring trends across different competitions.
- Identify his favourite opponents.
- Explore year-wise goal-scoring performance.
- Compare home and away goal contributions.
- Transform football statistics into meaningful visual insights.
